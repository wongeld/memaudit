# Synthetic city and occupation heatmaps

These charts represent all 40 profiles in the current synthetic pool, grouped by country. Each cell counts profiles sharing the named city and occupation; a dash means zero. `city_occupation_counts.csv` includes the zero-count cells.

If both attributes were already known, a cell with one profile would be unique only within this synthetic pool. It is not proof of identification, that an attacker learned either attribute, or of real-world risk. The dataset is small and not representative of a real population.

These are categorical grids, not geographic maps: cities are not positioned by coordinates. City and occupation names are normalized for matching; this does not resolve geographic ambiguity. No Step 3 answers, model calls, map services or geographic lookups are used.
